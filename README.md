# 🌍 Travel Expense Tracker

A modern Flutter application designed to help travelers manage their itineraries, track city stays, and monitor budgets effortlessly.

## ✨ Key Features
* **Tour Management:** Create and organize multiple travel tours.
* **City Tracking:** Keep a record of every city visited during your journey.
* **Expense Logger:** Stay on top of your budget with a dedicated expense tracker.
* **Sleek UI:** Features a custom **Glassmorphism** design using `glass_card.dart` widgets.
* **Local Storage:** All data is saved securely on your device using SQLite.

## 🛠️ Built With
* **Flutter & Dart** - Cross-platform mobile development.
* **Provider** - Efficient state management for tour and expense data.
* **Sqflite** - Robust local database handling for offline use.

## 📂 Project Structure
* `models/` - Data structures for Tours, City Stays, and Expenses.
* `providers/` - Logic for managing and updating app state.
* `database/` - SQLite helper for CRUD operations.
* `screens/` - The complete UI flow from Welcome to Detailed Expense views.
* `widgets/` - Reusable UI components like the Glass Card.
